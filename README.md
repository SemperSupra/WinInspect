# WinInspect

This repository is the **public deployment/release plane** for WinInspect.

Normal product development does **not** occur here. The authoritative development repository is private. Release source reaches this repository only through the approved constructive sanitization/projection process.

Until the first sanitized projection is reviewed and the repository is explicitly made public, this repository must remain a staging/deployment shell only.

Do not implement product fixes directly here. Do not add credentials capable of reading the private development repository.
